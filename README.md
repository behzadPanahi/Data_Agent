# همیار داده

MVP محلی برای ساخت عامل هوشمند متصل به پایگاه‌های داده با رابط فارسی و سه بخش تنظیمات مدل، ابزارهای پایگاه داده و گفت‌وگو.

## اجرا

Python 3.11 یا جدیدتر لازم است. در پوشه پروژه اجرا کنید:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app:app --reload
```

سپس `http://127.0.0.1:8000` را باز کنید. در لینوکس/macOS فعال‌سازی محیط مجازی با `source .venv/bin/activate` انجام می‌شود.

قابلیت‌ها: تنظیم API سازگار با OpenAI و مدل، مدیریت حافظه، افزودن و تست PostgreSQL/MongoDB/Elasticsearch/ClickHouse/Neo4j، کشف و ذخیره metadata، بازیابی ساده محلی metadata، اجرای ابزار کوئری با حداکثر چهار اجرا، گزارش روند و گفتگوی ذخیره‌شده.

## امنیت

این نسخه برای نمونه‌سازی محلی است. کلید API و اطلاعات اتصال به صورت متن در `data/state.json` ذخیره می‌شوند. فقط روی localhost اجرا و از کاربر دیتابیس read-only استفاده کنید. محدودسازی query جایگزین مجوزهای دیتابیس نیست. برای استقرار چندکاربره، احراز هویت، رمزگذاری اسرار، کنترل دسترسی و audit log لازم است. مدل باید از API سازگار با OpenAI و tool calling پشتیبانی کند.
